三大功能：

  • 改文字 — 左键点任意文字，Enter 保存
  • 复制 — 右键选 "复制一份"（可复制整张卡片）
  • 删除 — 右键选 "删除此项"

怎么用到我自己的项目？

在任意 HTML 页面 </body> 前加一行：

<script src="inline-editor.js" defer></script>

（可选）在 <head> 加一个 meta，避免多项目 localStorage 冲突：

<meta name="ed-project" content="my-app-v1">

（可选）自定义主题色，在 CSS 里覆盖变量：

:root {
  --ed-primary:      #3b82f6;
  --ed-primary-dark: #1e40af;
  --ed-primary-bg:   #eff6ff;
  --ed-primary-bd:   #bfdbfe;
  --ed-primary-text: #1e3a8a;
  --ed-primary-deep: #172554;
}

开发者 API

浏览器控制台可用：

InlineEditor.getState()   // 查看当前页所有修改（对象）
InlineEditor.clearPage()  // 清空当前页
InlineEditor.clearAll()   // 清空整个项目所有页
InlineEditor.export()     // 触发导出 JSON
InlineEditor.activate()   // 手动开启编辑模式
InlineEditor.deactivate() // 手动关闭
